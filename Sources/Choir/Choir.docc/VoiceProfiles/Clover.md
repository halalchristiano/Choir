# CLOVER

`choir.child.female.clover` · conditioning ID `6` · child/female · general

## Character

Soft-spoken sweetness; the trusting youngest sibling. Intended uses: dialogue
and narration.

| Design parameter | Value |
|---|---:|
| Median F0 / range | 265 Hz / 225...330 Hz |
| Formant scale | 1.22 |
| Spectral tilt | −7.5 dB/octave (`bright-soft`) |
| Breathiness / roughness | 0.30 / 0.03 |
| Tempo | 4.1 syllables/s |
| Pitch dynamism | 2.6 semitones |

## Supported-envelope target

Pitch −6...+6 st; rate 0.6...2.0×; emotion 0...1; breathiness 0...1;
age shift −1...+1; gender shift −1...+1. Production quality throughout
this envelope is not yet validated.

## Demo passages

1. “Will you stay until the rain stops?”
2. “I saved the smallest piece because I thought you might come back.”
3. “Clover carried the sleepy bird home in both hands and spoke to it all the way.”

## Suggested pairing

Gentle sibling dialogue: tender intent, emotion `0.4`, rate `0.9`, breathiness
`0.2`. Check intelligibility before increasing breathiness.
