# Documentation Status

Separate documented contracts from validated production capabilities.

| Area | Documentation | Runtime status in 0.16 |
|---|---|---|
| Installation and API tiers | Documented with compile-oriented examples | Public APIs exist; default synthesis is mock-backed |
| 32-voice catalog | All profiles, IDs, design parameters, passages, and pairings documented | Metadata profiles exist; distinct trained timbres do not ship |
| SSML-C | Parser grammar, values, diagnostics, and edge cases documented | Parser exists; not every style is acoustically realized end to end |
| Phonemes | Stable ARPAbet/IPA mapping and examples documented | Inventory and conversion API exist; audio examples await production assets |
| Integration recipes | Current building blocks and missing gates documented | One-call product-specific workflows are not complete |
| Platforms | Declared targets and divergences documented | Physical-device conformance is not established |
| Maintenance | Reproducibility contract, conversion, benchmark, and release gates documented | Training and asset-build implementations are absent |
| Responsible use | Disclosure, consent, privacy, and accessibility guidance documented | Consuming apps remain responsible for their own storage, analytics, and sessions |

Documentation does not waive an acceptance gate. A feature becomes complete
only when its implementation, tests, required assets, measurements, and
archived release evidence all exist.
